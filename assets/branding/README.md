# ByteBridge icon

`icon.png` is the shared source for the app UI and macOS installer icon. It is a 1254 × 1254 PNG with transparency. Electron-builder converts it to the platform icon format during packaging.

Created with the built-in image-generation tool. The source is intentionally kept outside the ignored build/output folders.

## Original generation prompt

Create one final polished desktop application icon for ByteBridge, a collaborative coding and debugging app. Square 1024x1024 image, transparent outside the icon. A dark charcoal-green rounded square tile (#192123), with a generous transparent outer margin of about 8 percent, containing a bold simple geometric mint-green (#b5e8cb) bridge mark: two sturdy symmetrical bracket-like bridge supports joined by one continuous horizontal deck, a clear arch-shaped negative space below. Subtly suggest two code brackets connected together; the shape must be instantly legible at 32px. Strong distinctive silhouette, balanced centered geometry, restrained flat vector-like design, very subtle depth to tile only. No text, no letters, no watermarks, no mockup, no multiple variations, no extra decorative dots, no thin lines. This is an actual downloadable app icon asset, not a presentation.
